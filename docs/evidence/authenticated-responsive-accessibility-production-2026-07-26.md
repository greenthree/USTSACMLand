# 真实认证响应式与可访问性结构验收（2026-07-26）

## 结论

使用一名已登录的真实成员账号，对生产域名 `https://ustsacm.fun` 的五个认证路由完成
桌面端与 390px 移动端只读验收。页面刷新后会话保持，五个路由均没有页面级横向溢出、
无名称交互控件、正 `tabindex` 或控制台 warning/error；主内容、导航地标和跳转链接结构
完整。

该响应式与结构检查阶段没有保存成员资料、触发同步、创建或修改训练目标、发送 AI
消息、导出个人数据、修改密码或执行其他生产写入。随后执行的训练目标生命周期烟测另见
`docs/evidence/training-goals-verification-2026-07-22.md`。本记录不包含姓名、邮箱、QQ、成员
UUID、平台账号、会话、Token、对话正文或接口响应正文。

## 静态可访问性结构

五个路由在桌面端和移动端均满足：

- 文档中的第一个可聚焦入口为指向 `#main-content` 的跳转链接；
- 存在唯一的主内容区域，并至少包含一个具有可访问名称的导航地标；
- 正 `tabindex` 元素数量为 0，没有依靠正数强行重排焦点；
- 无可访问名称的按钮、链接、输入框、选择框和文本域数量为 0；
- AI 助手的额度区、历史对话和对话工作台在 Accessibility Tree 中具有可识别结构。

这些结果证明静态 DOM 和浏览器 Accessibility Tree 没有已知结构性阻塞，但不能证明
真实键盘焦点顺序、焦点样式或屏幕阅读器朗读体验。

## 未完成边界

内置浏览器外壳会截留 `Tab`：页面级 `locator.press("Tab")`、浏览器输入层和 DOM 输入层
均不能推进焦点。随后尝试使用 Windows 级浏览器键盘控制，但工具因为当前 Windows
浏览器缺少 URL 安全策略校验能力而主动终止。

因此本证据明确不声称以下事项已经完成：

- 真实 `Tab` / `Shift+Tab` 顺序；
- 焦点环在所有背景和控件上的可见性；
- 屏幕阅读器的朗读顺序、控件状态播报、错误提示和动态区域播报；
- 真实移动设备或触屏辅助技术验收。

ROADMAP 将已完成的真实认证响应式与静态结构验收单独标记为完成，并继续保留人工键盘
和屏幕阅读器验收为未完成项。
