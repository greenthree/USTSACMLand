# 首页移动端与校内赛事调整

日期：2026-09-13（Asia/Shanghai）。本次未使用 skill。

## 首页显示修复

Chrome 390px 下复现：首页气球正常，但正文仍使用桌面双栏宽度，右侧内容延伸到约 845–923px，被 `overflow: clip` 裁掉。页面自身的 `scrollWidth` 仍为 390px，旧测试只检查页面和 Hero 边界，无法发现正文裁切。

根因是首页 CSS 延迟加载后覆盖了全局 `styles.css` 内的移动端规则。将首页正文的响应式样式移回 `home.css`，置于对应桌面规则之后，包含章节标题、能力矩阵、赛事列表、开放平台、学习资源、训练数据和招新时间线。全局文件仅删除迁走的首页规则，保留其他页面样式。

另外为平板标题角标预留单独空间，避免与标题重叠；手机时间线节点明确使用 border-box，并与竖线居中，悬停时不侵入赛事标题。气球源码、形状、色彩和物理交互未改动。

## 校内赛事调整

- 首页只显示校赛（11月）、练习赛（3月），按此顺序排列；赛事计数同步改为两场，校赛详情直达 `/contests/campus`。
- `/contests/campus` 默认展示校赛，第二项为练习赛。删除新生赛封面、详情、专属数据及入口；保留现有路由和组件文件名以避免无关迁移。
- 校赛改为单人赛：一人一台电脑、独立报名与解题；赛制概览、正文、准备清单、封榜说明和滚榜可见文案均同步修改。
- 根据后续要求，校赛调整为三小时，开赛后第 2 小时封榜、第 3 小时结束；保留 AC 题数优先及同题数比较罚时的规则。封面时钟、装饰数字、正文与滚榜示例提交时间同步调整，示例罚时按新提交时间复算。练习赛保留三小时个人天梯模拟与赛后队伍编排。JSCPC 后续组队不等于校赛组队。
- 更新主导航赛事描述、滑动顺序和边界；首页时间线与赛事选择器改为两列。
